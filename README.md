# 📊 Customer Churn Prediction

Predicting customer churn for a telecom company using supervised machine learning techniques.

## 📁 Overview
This project identifies customers likely to leave based on behavior and demographics. Helps businesses retain valuable customers.

## 🛠️ Tools Used
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib, Seaborn
- Jupyter Notebook

## Process
- Performs exploratory data analysis on telecom churn dataset.
- Applies Logistic Regression, Decision Tree, and Random Forest models.
- Includes visualizations such as churn rates by contract type and feature importance plots.
- Final model evaluated using accuracy, confusion matrix, and classification report.
